      綜上所述

      • 算得對數字由確定性規則引擎計算，每一格都指得回基準表與法源。
      • 審得清不符與需確認分開；推定值不判錯，承辦的裁決寫進意見書、留下紀錄。
      • 用得上送什麼都能逐格核算；沒送，也能依地號先產出一版。

      往下捲，沿路看六個接下來的應用場景 →

      A OPEN API

      開放 API：
      讓規則引擎成為共用的基礎建設

      • 對外提供版本化的 REST API（/v1）與公開的 OpenAPI 規格：送審核算、規則查詢、書表產出。
      • 估價師事務所送件前自行核算；地政事務所與需用土地人的系統直接串接，不必重打資料。
      • 回應附依據（條號、頁碼、基準表格位），別人的系統拿到結果也能追溯。

      現況後端已是 FastAPI，/docs 自動產生文件。下一步API 金鑰、用量上限、存取紀錄、版本管理。

      B SECURITY

      資訊安全：
      身分、權限、加密、稽核四道防線

      • 身分：接機關單一登入（自然人憑證、公務帳號），取代目前自填的操作身分。
      • 權限：承辦、主管、估價單位分角色，案件依轄區與層級授權。
      • 加密與稽核：傳輸 TLS、儲存加密、機密集中保管；操作紀錄加上雜湊鏈，任何竄改都驗得出來。

      現況HTTPS、對外只開 443／80、SSH 限單一 IP、操作紀錄。下一步單一登入、角色權限、雜湊鏈、定期弱點掃描與滲透測試。

      C NLSC LINK

      串接國土測繪中心：
      從開放圖資到即時地籍

      • 地籍圖資 API：即時宗地界線與面積，取代非即時的開放地籍查詢（以地政局名義申請）。
      • 門牌定位對上地籍：實價登錄的門牌自動落到宗地，判斷是否同一區段。
      • 20 m 數值地形模型、國土利用現況調查、正射影像：地勢、現況使用、建物有無自動判讀。

      可發展的新功能登記面積與圖面面積自動比對、界址異動提醒、三維建物的日照與視野分析。

      D SELF-CHECK · 建議

      送件前自主檢核：
      補正往返變少

      • 把同一套規則開給估價單位，送件前先核算一次，看到不符項與依據。
      • 審查端收到的是已經自檢過的書表，補正往返從多次降到一次。
      • 自檢結果附在送審資料裡，承辦一眼看出哪些已經處理。

      銜接與 A 開放 API 共用同一套規則；估價單位不必另學一套工具。

      E INSIGHT · 建議

      跨案一致性儀表板：
      看見哪些規則最常出錯

      • 彙整所有案件的不符與需確認，依審查重點 i–vii、細項、區域統計。
      • 找出最常出錯的地方（例如加總、跨表抄填），回饋到教育訓練與基準表修訂。
      • 同一區段不同年期的修正率並排，檢查判定前後是否一致。

      銜接每筆 finding 已經帶審查重點、書表、格位與依據，資料現在就有。

      F MORE CASES · 建議

      換一份基準表：
      支援更多地價業務

      • 引擎只讀規則 JSON：各縣市、各用地別的評價基準明細表匯入即用，不改程式。
      • 同一條「事實 → 等級 → 修正率 → 價格鏈 → 審查」，延伸到區段徵收、市地重劃、公告土地現值評議。
      • 基準表版本化：每一版都留存，舊案可以用當年的規則重算。

      現況已內建金山商業用地、樹林住宅用地兩份基準表，另可匯入 PDF／CSV／JSON。

# 12 地政局正式範本 xlsx 寫入器（格位對照）

決賽題目附三份 Excel 範本（`backend/app/templates/official/`），`app/output/official_xlsx.py` 直接把引擎結果寫進範本：格線、合併格、字型不動，只寫值；輸出時只留目標工作表。
API：`GET /api/cases/{id}/official.zip`（三份）、`GET /api/cases/{id}/official/{t3|t5|t4}.xlsx`；輸出頁「地政局正式範本書表」。
寫值一律寫在合併範圍左上格（`_anchor`）。「○本區段內　○本區段外(距」以 `_mark` 把對應的 ○ 換成 ●；勾選框 □ → ■。

## 決賽題目的對應（fixtures/shulin_case_1110901.json）

- 表5-1 備註「使用分區、建蔽率、容積率修正併同於比較法調查估價表宗地個別因素考量調整修正」→ `case.regional_no_adjust = ["R1-2","R1-3","R1-4"]`，表5 該三列填「-」不計入小計（`build_table5(no_adjust=…)`）。
- 期日調整率由題目給定（平均區段地價表），寫在 `comparables[].date_adjustment.pct`；拿到指數表後改由系統驗算。
- 個別因素 7～25 由開放地籍界線與圖資推定（標推定）；地籍圖或登記面積到手後以其為準。
- 容積率：題目 P002-00 勘查表填 200%、其餘三區段 260%；樹林住一分區上限兩版土管皆 260%，200% 為「面臨道路未達 8 公尺」但書值。系統以都市計畫圖道路用地量宗地面臨的計畫道路寬度（樹德段284：樹人街 7.3 m → 200%，與題目 P002-00 勘查表「樹人街 7 M、200%」一致；文林段317：潭興街 7.0 m → 200%，題目 P004-00 填 260%；太平段367、917 不鄰道路用地，面臨現有巷道 → 但書 200%，題目 P003-00 填 260%），宗地值與勘查表不一致者列需確認（docs/07 但書列）。

## 上傳題目 PDF 的自動流程（2026-09-12）

把「題目.pdf」（四張勘查表＋表5-1＋表4）當送審書表上傳：
1. 解析：四張勘查表各成一個區段（區段範圍文字用頁面全文補完整，不受表格欄寬截斷）；標題「(普通住宅用地)」→ 住宅用地；鄉鎮市區「樹林區」→ 優先選 `rules/shulin_residential_*`；表4 比較標的地號（含「367、917」多筆）、交易日期（民國年月日 → 110.09.14）、土地正常單價、期日調整率；表5 備註「…併同…」→ `case.regional_no_adjust`。
2. 建案：補比準地與比較標的界線（本案地籍圖 → 預載 → 開放地籍查詢）、四個區段依四至圍面。
3. 表4 個別因素全空白時自動「依地號產生」（overwrite=False，填載值不動）：宗地屬性、四個區段勘查表、設施距離。
4. 產出：系統版書表（勘查表每區段一頁）與地政局範本三份。

相關：`main.cases_save`（自動產生條件）、`adapters/pdf_forms._full_line`、`pick_rulesets(district=)`。

# 07 計算依據對照（每一條算式 → 法源 → 程式位置 → 驗證）

原則：數字不是「湊到跟範本一樣」就算對。每一步都要能指回《土地徵收補償市價查估辦法》（下稱辦法）條號或
《土地徵收補償市價查估作業手冊》（104 年 3 月版，下稱手冊）頁碼；範本與手冊不一致時以手冊／辦法為準，範本值標「疑點」。
本文件與 `basis.py` 的頁碼一律指手冊**印刷頁碼**（頁底數字）；PDF 頁序＝印刷頁＋4。辦法全文在手冊 p.115–123（`docs/reference/作業手冊_全文擷取.txt` 第 4575 行起）；手冊 p.100–102 有官方算例，本專案用它當第二組驗收資料
（`backend/tests/test_manual_examples.py`）。
介面的「法源提示」（欄位滑過顯示條號／頁碼）內容在 `backend/app/report/basis.py`，與本文件對照；改一邊要改另一邊。

## 疑點（範本或手冊本身）

- **A. 188,459**：184,763 × 1.02 = 188,458.26。要得到 188,459 與 212,958 兩個數同時成立，正常單價須為 184,763.4 左右，即範本的正常單價本身是四捨五入過的顯示值。引擎保留小數、審查容差 ±1 元（`PRICE_TOL`），Excel 寫未捨位值。
- **B. 等級數字欄**：手冊 p.49 (七)2 與 p.52 (八)2 都寫 2 級為「1 優 2 劣」、3 級「1/2/3」，範本表5 二級細項顯示「1 無」、表1 二級細項顯示「1 | 2」。引擎 `level_number` 自 2026-09-09 起依手冊（2 級 1/2、3 級 1/2/3）；範本慣例保留在 `rules.LEVEL_NUMBER_STYLE = "template"`，地政局若確認現行慣例是範本寫法再切回。表1 的第二欄是「等級總數」（2 或 5），不是等級。
- **C. 期日調整取整**：手冊未規定小數位數；範本 2.037% 填 2.00%。引擎不判錯，差 > 0.05 個百分點才提醒須備註。
- **D. 金山個別因素表道路種類 max 8 > 內政部上限 5**：已對照 `評價基準明細表範例.pdf` 第 7 頁矩陣（0/2/4/6/8），不是抄錯，是範例表本身超過附件25 商業用地上限。依約定不改 `rules/*.json`；`verify_rulesets` 每次核算都列「需確認」，不判錯。

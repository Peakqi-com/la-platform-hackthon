# 02 領域規則摘要（來自作業手冊，附頁碼）

手冊：內政部《土地徵收補償市價查估作業手冊》104 年 3 月版，169 頁。全文擷取在 `docs/reference/作業手冊_全文擷取.txt`。
注意：手冊是 104 年版，範本是 114 年案件；表號不同（手冊表3=勘查表，範本標表1），格式大致相同，以範本為準。

## 流程（p.3–10）

1. 蒐集基本圖籍
2. 調查買賣/收益實例、影響地價因素
3. **劃分地價區段**、繪地價區段圖
4. 估計實例土地正常單價（買賣實例調查估價表）
5. 選取比準地、查估比準地地價（表5 區域因素分析 → 表4 比較法）
6. 估計各宗地市價（徵收土地宗地市價估計表，以比準地為基準做個別因素調整）
7. 提地評會

書表製作單位（p.16）：表1–5、表8 查估單位；表7 宗地個別因素清冊 = **需用土地人**填；表9 評議表 = 市府。

## 審查重點（p.11–13）— 系統 findings 的條號來源

- **iii** 勘查表區段範圍描述與現況相符；各用地別應評價細項皆已填；優劣等級依「區域因素評價基準明細表」填列
- **iv** 地價區段劃設符合規定，區段圖/略圖清晰、路名地標可辨識

- **vii** 表4 交易日期與實例表一致；**區域因素調整百分率 = 表5 總修正數**；個別因素差異率依個別因素基準明細表；各比較標的權重合邏輯
- **ix** 比準地地價估計表區段號、比準地標示、估值與表4 一致；尾數計算
- **x** 宗地市價估計表各宗地條件與清冊一致；差異率依基準明細表；尾數
- 委託估價師時，估價師須檢附其採用的區域/個別基準明細表（p.12）

## 距離量測（p.24, 8(1)–(3)）— 「直線距離和步行距離」的出處

- 各設施影響距離因地制宜，需用土地人填清冊前應洽地政事務所了解基準表級距
- **同一細項多個設施 → 填對當地影響最大者；同一徵收案填寫基礎一致（皆以某主要學校）**
- **量測標準依「是否因通達該地點而影響地價」決定：學校、市場需通達 → 路線距離；嫌惡設施（焚化爐空污）→ 直線距離。無論採哪種，每一案各細項量測標準須一致。**
- 問答十一（p.78）：最大影響距離因地制宜，先洽地所

→ 實作：`rules/facility_measurement.json` 定預設，UI 可逐項覆寫，案件層級先選參照設施再逐宗地算。

## 基準明細表訂定原則（p.48–49 區域、p.52 個別）

- 適用範圍原則以鄉鎮市區為單位，可合併或再細分
- 等級劃分：2 級（優/劣）、3 級（優/普通/劣）、5 級（優/稍優/普通/稍劣/劣）、7 級、9 級
- 各細項在內政部「最大影響範圍」內（`rules/moi_max_ranges.json`）
- 情況特殊可於備註敘明後酌調修正百分比，仍不得超過最大影響範圍
- 個別因素：面積、寬度、深度、形狀間避免重複修正；不規則形寬深得不考量

## 表5 填寫（p.41–49）

- 等級須與勘查表調查之基本資料相符（→ findings vi）
- 修正百分比：比準地區段等級 × 比較標的區段等級 對照基準明細表級距
- **總修正數 = Σ 各主要項目小計**；帶入表4「區域因素調整」欄
- 各用地別有各自的表：5-1 住宅、5-2 商業、5-3 工業、5-4 農業、5-5 其他。**細項不同**（住宅有學校、服務性設施、日照景觀傾斜度、土地改良；商業有工商活動 6 項）

## 表4 填寫與計算（p.50–53）— 逐條法源對照見 docs/07_calculation_basis.md

- 案號、比準地基本資料依清冊；比較標的依買賣實例調查估價表
- 期日調整：得以地價指數、房價指數或物價指數；範本用都市地價指數 (當期/交易期)−1，填至 2 位小數（範本「約 2%」填 2.00%）
- 個別因素：依比準地所屬使用分區選同性質用地的基準表；**免修正項目填「-」**，與差異率 0 區分；免比較項目於備註敘明理由
- **計算式（依 p.100–101 範例驗證，乘法）**
  - 調整至估價基準日單價 = 正常單價 × (1+期日%)
  - 試算價格 = 調整至基準日單價 × (1+區域總修正%) × (1+個別合計%)
  - 絕對值加總 = |期日| + |區域| + Σ|個別|
- 相近程度與權重（p.53 (十一)）：絕對值加總愈大權重愈小；範例 3 件 7/10/15% → 較高/普通/較低 50/30/20；2 件 → 70/30；**1 件 → 普通 100%**
- **比準地比較價格尾數四捨五入至個位數**（p.53 (十二)）
- 範本備註：案例稀少時依查估辦法 §17-3 放寬蒐集期間至一年、§19-2 擴大範圍；只選 1 筆案例需說明理由

## 地價尾數（p.9–10 (六)）— 比準地地價與宗地市價

| 每 m² 單價 | 計算至 | 尾數 |
|---|---|---|
| ≤100 元 | 個位 | 無條件進位 |
| 100–1,000 | 十位 | 無條件進位 |
| 1,000–100,000 | 百位 | 無條件進位 |
| >100,000 | 千位 | 無條件進位 |

## 公共設施保留地（p.63–74）

按毗鄰非公設保留地區段的加權平均（區段線長度 × 區段地價）；含公設用地區段時從高；§22-4 情形以 3 個同性質區段平均。不在 MVP，但當天若標的是公設保留地要能講出來。

## 範本裡的推定與疑點（要在 UI 標「需確認」）

1. 特殊設施多個（變電所 700m 稍劣、加油站 440m 劣）填「劣」→ 推定取最不利者
2. 區域因素「本區段外(距 X M)」起點 → 推定為區段邊界最近點
3. 金山個別因素表「道路種類」max 8 > 內政部附件25 商業用地上限 5（已對照 PDF 第 7 頁矩陣 0/2/4/6/8，非抄錯）→ 不改 JSON，`verify_rulesets` 每次核算列「需確認」
4. 期日調整 2.037% 填 2.00%；中間值帶小數（184,763.4 才能同時得到 188,459 與 212,958）→ 引擎保留精度、比對容差 ±1
5. 表5-2 的「有無禁止建築／有無限制建築」兩列，範本顯示「1 無」而不是「1 優」→ Excel 輸出照範本顯示「無／有」（`xlsx.level_label`），抽取器把「無／有」正規化回「優／劣」再比對（`pdf_forms._norm_level`）
6. 基準明細表 PDF 有兩處單位錯字：站牌「200km以上未滿400m」、觀光遊憩「1,000km以上未滿1,500m」→ `rules_table` 視為公尺並 warning，不改 rules JSON
7. 基準明細表沒寫「無設施」與「區段內有」時的等級（交通運輸、公共建設、特殊設施、環境污染各項）→ 手抄 JSON 與 `rules_table` 都用同一推定：愈近愈好者「無→劣、區段內→優」，嫌惡設施「無→優、區段內→劣」，轉表時逐項 warning「需確認」
8. 金山個別因素表「臨路情形」= 內政部「臨街情形」；區域表「使用分區﹝編定﹞」= 內政部「使用分區（使用地類別）」，名稱差異由 `rules_table` 的目錄別名吸收
9. 估價師的表不會寫距離的量測方式與起點 → 從表1／表4／表7 抄來的 Facility 依 `facility_measurement.json` 帶預設 measure、origin 依 scope（區域=區段邊界、個別=宗地質心），標 `assumed: true`，UI 要顯示為推定（使用者決定 2026-09-06）
10. 表7 官方 Excel 是轉置版面（欄位是列、宗地是欄，手冊 p.85），15–20 各兩列（名稱／距離）、25 兩列（有無／情形）；「-」表示免填而非缺欄，21/23/24 在非都市土地常為「-」

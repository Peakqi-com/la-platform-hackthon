## 實際上線的首頁（城市起風）

| 項目 | 位置 |
|---|---|
| 原始碼（不要直接改） | `city-wind-source/city-wind/dist/`，維持原樣 |
| 實際服務的副本 | `frontend/public/city-wind/` |
| 路由 | `next.config.ts` 的 `rewrites.beforeFiles`：`/` → `/city-wind/index.html` |
| 舊介紹頁 | `frontend/app/page.tsx` 留著當退路，rewrite 失效時 `/` 不會 404 |

**更新原始碼的流程**（原始碼換新版時照做）：

1. 保留 `enter.css`，其餘清掉，再把 `city-wind-source/city-wind/dist/` 整個複製過去（含 `systems/` 子目錄）。
2. 重套下列三處整合（`index.html` 目前在改版間維持不變，可原樣重套）。
3. **一定要重新 `npm run build`。** Next 的 `public/` 檔案清單在 build 時決定，
   build 之後才新增的檔案或目錄會 404。`systems/` 就是這樣踩到的。

整合時在副本上做了三件事，原始碼那份沒動：

1. **資源路徑改絕對路徑。** 原本是 `./style.css`、`./app.js`，在 `/` 底下會解析成 `/style.css` 而 404，
   改成 `/city-wind/…`。`app.js` 內部的 `./city.js`、`./three.module.min.js` 是相對模組網址解析，不必改。
2. **加入系統入口** `frontend/public/city-wind/enter.css`（只加不改，沿用原站的 `--accent` / `--line`）：
   頁首「進入系統 →」與結尾「進入案件總覽 →」，都指向 `/dashboard`。
3. **結尾兩個出口並成一列**（`.ending-actions`）。分開直排會把原本的「重新走進城市」擠到頁尾 HUD 上，
   在 1280×720 重疊約 50 px。

**「頁面當掉」先查測試環境，再查程式。** 這批改完第一次載入就掉回 `about:blank`，一度以為是新程式把渲染器打掛。
用二分法逐一換回舊檔測試，三個變體都活著；清掉殘留的 `chrome-headless-shell` 後，完整修改版在 LOW 與 MEDIUM 都正常，
五個章節都捲得完。結論是測試瀏覽器累積殘留程序造成的，不是程式問題。遇到同樣現象時，先清殘留程序、確認非 3D 頁面能載入，再懷疑程式。

**結尾那 6 個 404 是 logo 檔案槽。** `logos/*.png` 還沒提供，CSS 背景圖找不到檔案，只會在 console 留 404，畫面不受影響。

**測試環境的 KHR_parallel_shader_compile。** headless 的軟體渲染不支援平行編譯，`compileAsync` 會退回輪詢，載入約 5～8 秒；
使用者的 Chrome（Windows ANGLE）支援平行編譯，會快很多。載入畫面變長是刻意的：寧可多等幾秒，也不要第一次捲動時卡頓與黑閃。

## 動起來的規矩

- **一個物件，六個狀態。** 整頁只有一個主體在變形：三維區段 → 攤平的鏈 → 對照表 → 數字 → 書表。不是六段各做各的特效。
- **捲動驅動，不自動播放。** 現場講解會停頓，自動播放的東西會講到一半跑掉。
- **靜止也要看得懂。** 關掉 JS、`prefers-reduced-motion`、投影機掉幀，訊息都不能少。
- **效能預算。** 首屏 1.5 秒內可讀；three.js draw call < 60、三角形 < 30k；捲動只改 `transform` 與 `opacity`。
- **字級不縮。** 首頁基準可用 16–18 px 換版面呼吸，但委員要讀的數字與標籤不得小於 16 px。

## 技術決定

| 項目 | 決定 | 理由 |
|---|---|---|
| three.js / d3 | 走 npm 進 bundle | 不依賴外部 API 是專案原則；CDN 斷了首頁就毀了 |
| 字型 | 自架 woff2 放 `public/` | 同上，中文字型尤其大 |
| 3D 資料 | 只用 `fixtures/` 已進 git 的幾何 | 首頁不依賴 `data/`，重建失敗也不影響開場 |
| 體積 | three.js 動態 import，首屏不含 | 首屏可讀優先於 hero 早零點幾秒出現 |
| 深淺主題 | 首頁固定深底，系統固定紙底，不做切換 | 多一個狀態就多一組要測的畫面 |
| 動畫庫 | 不裝，用 `IntersectionObserver` + CSS | 需求只有捲動進度與 transform |

## 不做的事

- 不做粒子、星空、漸層光暈。有真的地籍界線與真的距離，用假的裝飾反而扣分。
- 不做數字跑馬。212,958 是驗收過的值，安靜待著比滾上去有說服力。
- 不碰系統內頁。內頁的冷灰改色列為賽後項目。
- 不放團隊介紹與比賽字樣（沿用「介面文字不出現主辦、比賽等字樣」的既有約定）。
